# BC2 Community

Сайт: https://bc2.uplay2.ru · Мастер: master.bc2.uplay2.ru

Лаунчер для существующей Battlefield: Bad Company 2 на Windows 10/11 x64.
Он не устанавливает игру, не меняет игровой EXE и не хранит аккаунты игроков.
В игре обновляет dinput8.dll и параметры подключения bfbc2.ini.
Собственное приложение и зависимости обновляет отдельно, сохраняя предыдущую версию.

## Пользователю

Скачайте `BC2Launcher-0.2.2-portable.zip`, распакуйте целиком в отдельную от игры
папку и запустите `BC2Launcher.exe`. Установка в Windows не требуется.
Самообновление сохраняется. Не распаковывайте новую версию поверх работающей:
используйте встроенное обновление либо отдельную папку.
Установщик `BC2Launcher-Setup.exe` остаётся дополнительным вариантом.
Выберите папку с BFBC2Game.exe, нажмите «Обновить», затем «Играть».
Обновления обязательны; без успешной онлайн-проверки запуск из лаунчера недоступен.
Прямой запуск EXE самой игры лаунчер не блокирует.

Резервные копии находятся в папке игры `.bc2-launcher/backups/`.
Кнопка «Откатить» восстанавливает выбранную копию; обязательный выпуск продолжает
проверяться. Общий откат администратор выпускает новой ревизией с прежними файлами.

## Разработка

Python 3.12. Создать `.venv`, установить `requirements-lock.txt`.
Запуск исходников: `.venv\Scripts\python.exe launcher\run_launcher.py`.
Автотесты: задать `PYTHONPATH=launcher`, выполнить
`.venv\Scripts\python.exe -m unittest discover -s launcher/tests`.
Сборка: `tools/build.ps1 -Versioned -Version 0.2.2` с локальным ключом подписания
и Inno Setup ISCC.exe. Сборщик изолирует поиск DLL от посторонних программ
в PATH. Он создаёт клиент, постоянный загрузчик, подписанный ZIP обновления,
переносимый ZIP и установщик
после self-test обоих EXE. Проверка Qt и ресурсов без открытия окна:
`BC2Client.exe --self-test --report report.json`.
При ошибке команда возвращает ненулевой код и записывает причину в JSON.
Для проверки новой версии рядом со старой: `tools/build.ps1 -Versioned`.
Результат находится в `dist/local-<версия>/`; установленный лаунчер
не перезаписывается сборщиком. Геометрическая иконка собирается `tools/build_icon.py`
в SVG для сайта и ICO с девятью размерами для EXE/окна Windows.

## Выпуски

Самообновление программы: [схема, проверка и выпуск](docs/SELF_UPDATE_RU.md).
Канал `updates/launcher-stable.json` отделён от описанного ниже канала игровых файлов.
Старым 0.1.x требуется один раз скачать новую сборку ZIP либо установить Setup.
Помощь: [FAQ](https://bc2.uplay2.ru/help.html). Кнопка в лаунчере открывает эту
страницу в браузере. Источник — `docs/FAQ_RU.md`, `tools/build_help.py` формирует
страницу; `--check` проверяет актуальность генерации.

Секретный ключ хранится вне Git и всех ZIP. Ключ этого проекта находится только
на компьютере выпускающего; публичный ключ включён в лаунчер. Сделайте приватную
резервную копию ключа, иначе следующие обновления невозможно подписать тем же ключом.

`tools/release.py package --folder <пакет> --base-url <URL-выпуска> --package-id <имя>
--private <ключ> --revision <новый-номер> --output website/updates/stable.json`

Манифест действителен 90 дней; обновляйте подпись/срок новой ревизией до истечения.
Каждая ревизия неизменяема. Для возврата старых файлов используйте подкоманду
`rollback` с новой ревизией. Ошибочная подпись, старый номер или истёкший срок
блокируют кнопку запуска. Не удаляйте счётчик highest_revision из настроек игроков.

Проверенный резервный источник политики — raw.githubusercontent.com этого
репозитория. Используется только при недоступности сайта, проверка подписи та же.
Ключи, мастер, база и конфигурация серверов в этот репозиторий не входят.

## Важно для приёмки

Сборка и автотесты не доказывают реальный вход в BC2/Vietnam. Испытания игры
выполняет пользователь по `docs/TEST_RU.md`. Публичная тестовая сборка не означает
начала массового перехода игроков и не меняет действующий мастер.
