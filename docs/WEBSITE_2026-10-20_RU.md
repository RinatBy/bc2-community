# Страница BC2.uplay2.ru, 20.10.2026

Пользователь разрешил публикацию сайта и попросил снять старые сборки лаунчера.
Новая визуальная версия лаунчера сначала проверяется локально. Её EXE и ZIP
не публикуются вместе с этим изменением страницы.

На странице оставлены название BC2.uplay2.ru, фон Valparaiso, прежний слоган,
кнопка «Файлы проекта» и четыре коротких шага подключения. Вход, регистрация
на сайте, раздел «Свой сервер» и ссылка на старый лаунчер убраны. Аккаунт
создаётся в самой игре; API регистрации сайта не реализован.

Файлы проекта: `BC2-connection-files.zip` в выпуске `v0.1.0-test`.
В ZIP только dinput8.dll, bfbc2.ini и README.txt. DLL и INI совпадают с уже
проверенными файлами подписанного канала; в INI host=master.bc2.uplay2.ru.
Ключи, база и игровой EXE в комплект не входят.

SHA-256 ZIP:
`0856bab442f148db622b3e4c688c2c4ff544c8c87b8e2f04c77bf0b754469d03`.
Такой же digest и размер 19 871 байт подтверждены GitHub после загрузки.

Пользователь подтвердил реальное подключение в игру через домен мастера.
DNS мастера: master.bc2.uplay2.ru → 95.31.234.79. Для сайта необходима
отдельная запись CNAME: bc2 → rinatby.github.io в зоне uplay2.ru.

Страница проверена в браузере: оба локальных шрифта загружаются, на широком
экране нет прокрутки и горизонтального переполнения; на мобильной ширине
горизонтального переполнения нет. Инструкция и ссылка проверены в DOM.
