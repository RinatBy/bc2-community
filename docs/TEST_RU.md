# Ручная приёмка тестового лаунчера

1. Закройте игру. Сохраните прежние dinput8.dll и bfbc2.ini отдельно от папки игры.
2. Распакуйте BC2Launcher-0.2.2-portable.zip целиком в отдельную папку. Запустите
   BC2Launcher.exe из неё. Устанавливать приложение не требуется. Не копируйте
   архив поверх работающей или старой папки; игра в архив не входит.
3. Выберите существующую папку с BFBC2Game.exe;
   ранее сохранённый путь должен сохраниться, если настройки уже были на этом ПК.
4. Должно появиться предложение установить обязательное обновление. До него
   «Играть» недоступно. Обновите, проверьте host=master.bc2.uplay2.ru в [info].
5. Прочие параметры существующего INI должны сохраниться. Игровой EXE не меняется.
6. Нажмите «Играть», войдите в старый аккаунт, проверьте список серверов и матч
   BC2/Vietnam. После повторного входа проверьте опыт и SPECACT.
7. Закройте игру. Нажмите «Откатить», выберите копию. Два прежних файла восстановятся;
   если INI раньше отсутствовал, он будет удалён. Запуск требует очередной проверки.
8. Для теста обязательности администратор публикует следующую ревизию с иным
   комплектом. Уже открытый лаунчер должен обнаружить её при нажатии «Играть».
9. Для общего отката публикуется НОВАЯ ревизия с прежними исправными файлами.
   Игрок обновляется обычной кнопкой; номера ревизий назад не переводятся.
10. Без интернета должны появляться ошибка проверки и блокировка запуска.
    Отмена загрузки не должна менять файлы. Не выключайте ПК ради проверки:
    восстановление после прерывания покрывается автоматическими тестами.

Если после замены файлов старая игра сообщает об отсутствии MSVCR100.dll или
MSVCP100.dll, проверьте установленный Microsoft Visual C++ 2010 SP1 x86.
Не скачивайте отдельные системные DLL. Лаунчер не заменяет эту зависимость.

Для отчёта достаточно версии лаунчера, текста ошибки и этапа. Не присылайте пароль,
базу или ключи. Настройки самого лаунчера: `%LOCALAPPDATA%/UPLAY2/BC2Launcher/`.

Мастер задаётся доменом master.bc2.uplay2.ru. Его IP администратор меняет в DNS
при переезде; DNS и игровой вход — разные проверки.

## Самообновление 0.2.x

- Папка по умолчанию: `%LOCALAPPDATA%/Programs/BC2Launcher`; настройки по-прежнему
  `%LOCALAPPDATA%/UPLAY2/BC2Launcher/settings.json`.
- Первую версию с самообновлением нужно один раз распаковать из полного ZIP
  либо поставить через необязательный Setup. Старые 0.1.x эту замену не выполняют.
- При новом пакете появляется отдельная строка и «Обновить и перезапустить».
  Она активна после проверки пакета; обязательный минимум блокирует «Играть».
- При новой политике программа проверяет её и перед самим запуском игры.
- При сбое запуска новой версии возвращается проверенная предыдущая;
  требование обязательного минимума сохраняется.
- В текущем локальном установщике есть подписанная начальная политика для 0.2.0.
  Новый публичный канал пока не размещён. Отсутствие предложения обновления самой
  программы в этом локальном тесте ожидаемо; настоящий переход двух EXE проверяет
  изолированный runner из `SELF_UPDATE_RU.md`.
- Проверьте читаемость новой строки, сохранение выбора игры, отсутствие лишних
  адресов и нормальное закрытие во время фоновой проверки. Игровой вход проверяет
  пользователь; автоматические тесты игру не запускают.
- В 0.2.2 «Помощь» открывает https://bc2.uplay2.ru/help.html в обычном браузере.
  Отдельное окно справки убрано. В ZIP самообновление работает в распакованной папке.

## Счётчик онлайна, локальная 0.1.7

Справа вверху показана сумма игроков из каталога мастера, обновляемая раз в
30 секунд. Вход в аккаунт не требуется. Зайдите на разные игровые серверы и
сравните сумму с показателем лаунчера. Ожидающие входа JP отдельно не считаются.
Если каталог недоступен, показывается прочерк; это не должно менять проверку
игровых файлов или разрешение запуска. При закрытии во время опроса окно должно
закрыться после отмены запроса без сообщения QThread destroyed while running.
