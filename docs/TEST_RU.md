# Ручная приёмка тестового лаунчера

1. Закройте игру. Сохраните прежние dinput8.dll и bfbc2.ini отдельно от папки игры.
2. Распакуйте ВЕСЬ ZIP лаунчера. EXE должен находиться рядом с папкой `_internal`.
3. Запустите BC2Launcher.exe. Выберите существующую папку с BFBC2Game.exe.
4. Должно появиться предложение установить обязательное обновление. До него
   «Играть» недоступно. Обновите, проверьте host=master.bc2.uplay2.ru в [info].
5. Прочие параметры существующего INI должны сохраниться. Игровой EXE не меняется.
6. Нажмите «Играть», войдите в старый аккаунт, проверьте список серверов и матч
   BC2/Vietnam. После повторного входа проверьте опыт и SPECACT.
7. Закройте игру. Нажмите «Откатить», выберите копию. Два прежних файла восстановятся;
   если INI раньше отсутствовал, он будет удалён. Запуск требует очередной проверки.
8. Для теста обязательности администратор публикует следующую ревизию с иным
   комплектом. Уже открытый лаунчер должен обнаружить её при нажатии «Играть».
9. Для общего отката публикуется НОВАЯ ревизия с прежними исправными файлами.
   Игрок обновляется обычной кнопкой; номера ревизий назад не переводятся.
10. Без интернета должны появляться ошибка проверки и блокировка запуска.
    Отмена загрузки не должна менять файлы. Не выключайте ПК ради проверки:
    восстановление после прерывания покрывается автоматическими тестами.

Если после замены файлов старая игра сообщает об отсутствии MSVCR100.dll или
MSVCP100.dll, проверьте установленный Microsoft Visual C++ 2010 SP1 x86.
Не скачивайте отдельные системные DLL. Лаунчер не заменяет эту зависимость.

Для отчёта достаточно версии лаунчера, текста ошибки и этапа. Не присылайте пароль,
базу или ключи. Настройки самого лаунчера: `%LOCALAPPDATA%/UPLAY2/BC2Launcher/`.

DNS на 19.10.2026: master.bc2.uplay2.ru → 87.249.43.129. Администратор должен
подтвердить, что это текущий доступный мастер. DNS и игровой вход — разные проверки.
